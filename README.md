# Mayur Habib — Personal Portfolio & Resume

A modern, responsive, and mobile-friendly personal portfolio, curriculum vitae, and bio-data website built with pure HTML5, CSS3, and vanilla JavaScript.

## 🚀 Features
- **Modern Design**: High-contrast typography with `Manrope` and `DM Sans` fonts, custom gradients, and floating orb decorations.
- **Dark Mode**: Persistent theme toggle (`☾` / `☀`) using `localStorage`.
- **Responsive Layout**: Designed for mobile, tablet, and desktop screens with fluid grids and scroll-safe tables.
- **Pages**:
  - `index.html`: Hero introduction, quick academic facts, and featured highlights.
  - `resume.html`: Career objective, educational qualification, technical skills, projects, achievements, and hobbies.
  - `biodata.html`: Detailed personal information, languages known, declaration, and signature.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Custom Variables, Responsive Media Queries)
- JavaScript (DOM manipulation & Theme persistence)
